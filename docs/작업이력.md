# TRACE 작업 이력과 결정 사항

사용자와 나눈 대화에서 정해진 요구사항과 결정을 시간 순으로 정리했다. 다른 컴퓨터나 클라우드에서 이어서 작업할 때 참고한다.

## 출발점
1. **SAP 보험사 시산표·자산운용 양식** (`legacy/SAP_보험사_시산표_자산운용_양식.xlsx`): K-IFRS 17·9 계정과목, 전표(BKPF/BSEG), 합계잔액시산표, 자산운용명세, GL 대사.
2. 망분리 금융권에서 AI로 만들 만한 도구 논의 → **예산 대비 실적 리포트**와 **사업비 분석 도구**를 우선 과제로 선정.
3. 기술 결정: 내부망 반입 가능 = **엑셀·VBA·HTML**. Excel 2016. 매크로 사용 가능.
4. **예산실적리포트 v0.1** (`legacy/예산실적리포트_v0.1/`): 수식 버전, 자가진단, 예외목록, 코멘트.

## TRACE로 통합
- 사용자 설명: SAP **예산판** 화면은 부서·계정별 분기 실적/배정/조정/잔여를 보여주지만 **클릭해야 세부 전표**를 볼 수 있다. 예산판 + TB(+전표)를 넣으면 전월·전년동기·전분기 변화, 예산 여유, 급등 부서·계정, 전표 패턴 기반 원인 추정까지 하고 싶다.
- 판단: 원인 추정은 **전표 일괄 추출**(적요·거래처·코스트센터)이 가능해야 하며, 내부망에 AI가 없으므로 **규칙 기반 가설**(근거 강도 + 근거 전표)로 만든다.
- 이름: **TRACE / 사업비 원인추적기** (Trend · Risk · Anomaly · Cause · Expense). 정식 과제명: 사업비 변동 원인분석 및 예산 점검 자동화.
- HTML vs 엑셀: **엑셀이 본체**(입력·계산·근거·감사 대응), **HTML은 보기 화면**.

## v0.5 결정 (사용자 설명 그대로)
- **사업비 배부:** IFRS 4·9 기준으로 전표 → 계정별·부서별로 IFRS 17 계정대체 → 부서별·상품·증권번호별로 공통비 귀속.
- **계정대체 규칙:**
  1. 특정 계정이면 바로 IFRS 17 특정 계정으로 (직접대체). → `계정매핑`의 IFRS17 대체구분·직접대체 계정
  2. 공통비인데 유지비 성격이고 **투자관련부서**가 쓴 돈은 **일정 비율(1년에 1번 변동)**로 **재산관리비**로 넘김. → `계정대체기준` 1번 표
  3. 그다음 어느 부서가 쓴 공통비인지에 따라 **부서별 비율**대로 계정대체. → `계정대체기준` 2번 표
  4. 상품·증권번호별 귀속은 결과를 받기 전까지 포트폴리오 비율로 대신. → `계정대체기준` 3번 표
- **VFA도 분석에 포함** (PL에 영향): VFA 신계약비 차이 → CSM 조정, 유지·수금비 차이 → 당기손익. GMM·VFA 브리지를 따로 보여줌.
- **예산 통제 단위:** 부서 × 계정별 한도, **기간 단위는 분기**. → 변동분석 AJ~AO열 분기 한도 점검(여유·주의·초과 예상·한도 초과·무예산)이 주 판정, 연간 전망은 참고.
- **HTML·대시보드:** 엑셀에서 산출한 결과(data.js·JSON)나 **엑셀 자체를 업로드**하는 기능. 상단 메뉴바, 한 페이지에 몰지 말고 탭·페이지로 분리.
- **설명서:** 엑셀과 HTML 동작 원리·사용법 (`TRACE_사용설명서.html`, `docs/사용설명서.md`).
- **GitHub:** 다른 컴퓨터에서도 이어서 할 수 있게 필수 요소를 모두 올림. 이후 클라우드 세션으로 전환.

## v0.5 이후 추가
- **내려받기 페이지:** 엑셀 본체·입력 양식 7종(`samples/TRACE_입력양식_v0.5.xlsx`)·감독원 샘플·전체 ZIP. 대시보드 첫 화면에 [자료 불러오기]·[엑셀 양식 내려받기]를 큰 타일로.
- **예산 고갈 예상:** 사용자 "월별 데이터를 넣고 월별로 모니터링. 예산 소모속도를 선형함수로 만들어 예상 고갈시점 표시". → 연초 0부터 월별 누계에 최소제곱 직선, 연간가용에 닿는 날. 분기는 경과 개월 평균 속도.
- **디자인:** 공통 `trace.css`로 통일, IFRS 17 연결도를 7단계 열 + 진행 막대 + 측정모형 카드로 다시 그림.

## 확인이 필요한 것 (사용자에게 물어볼 것)
1. 실제 SAP 예산판·전표 화면 열 구성, 감독원 업무보고서 실제 양식 (항목코드·변동요인 코드).
2. 공통비 귀속 결과를 받을 수 있는 최소 단위 (상품코드? 계약집단?), 배부 기준과 산출 시스템.
3. 계리 예정사업비의 단위.
4. 계정대체가 SAP에 대체전표로 남는지 (남으면 TRACE 계산과 대사 가능).
5. 분기 한도에서 미사용분 이월 여부 (지금은 분기별 독립으로 가정).
