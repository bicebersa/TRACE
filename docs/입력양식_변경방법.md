# 입력 양식 바꾸는 법

TRACE의 수식은 원본 시트의 **표준 열** 기준이라, 실제 SAP 화면이나 감독원 양식이 달라도 수식은 고치지 않습니다. 아래 표만 맞추면 됩니다.

## 1. 열 이름·순서가 다를 때 → `헤더설정` 시트

| 칸 | 뜻 |
|---|---|
| 표준 열 | TRACE 원본 시트의 열 (고정) |
| 찾을 헤더 이름 | 실제 파일의 머리글. 이 이름으로 열을 찾습니다 |
| 대체 이름 | 쉼표로 여러 개. 찾을 헤더 이름이 없으면 차례로 시도합니다 (예: `금액(원),현지통화금액,DMBTR`) |
| 필수 | 필수 열을 못 찾으면 불러오기를 멈추고 어떤 열이 없는지 알려줍니다 |
| 없을 때 | 선택 열이 없으면 빠지는 기능 |

- 띄어쓰기, 대소문자, 줄바꿈은 무시하고 비교합니다.
- 파일 위쪽 20행(입력옵션에서 변경) 안에서 헤더 이름이 가장 많이 맞는 행을 머리글로 봅니다.
- 열 순서는 상관없습니다.

## 2. 불러오기 규칙 → `입력옵션` 시트

| 옵션 | 쓰임 |
|---|---|
| 제외할 행 키워드 | `합계,소계,총계,Total`처럼 합계 행을 빼는 단어 |
| 전표 금액 방식 | `부호 있는 금액` 또는 `차대구분+양수금액` (SAP 차대구분 S/H). 대변 표시 값인 행은 금액에 −를 붙입니다 |
| BS·PL 양식 형태 | `세로 (기간×항목)` 또는 `감독원 (가로)` |
| 가로: 당기·전기·누계 헤더 | 감독원 양식의 금액 열 이름 |
| 가로: 전기 열의 기간 | 전기 열을 `전년말`(전년 12월) 또는 `전년동월`로 저장 |

감독원 가로 양식은 **설정의 기준월 한 달씩** 불러와 기존 자료에 합칩니다. 같은 달을 다시 불러오면 그 달만 바뀝니다.

## 3. 코드 체계가 다를 때 → `입력옵션` 아래쪽 매핑 표

- **BS·PL 항목 매핑:** 회사(감독원) 항목코드 → TRACE 표준 코드 (A000 자산총계, L130 CSM, P300 기타사업비용 등). 코드가 없으면 항목명으로 찾습니다.
- **변동표 요인 매핑:** 감독원 양식 변동요인코드 → TRACE 요인코드 (F10 신계약, F21 가정변경-사업비, F31 경험조정-신계약비 등).
- 매핑에 없는 코드는 원래 코드 그대로 쓰므로, 표준 코드로 된 자료는 매핑 없이도 동작합니다.
- 기본값은 예시 감독원 양식(`samples/`)의 코드입니다.

## 4. 계정·부서·배분 체계 → 매핑 시트

| 시트 | 고치는 것 |
|---|---|
| 계정매핑 | G/L → 사업비 항목, 사업비 여부(Y/제외) |
| 부서매핑 | 코스트센터 → 부서 (조직개편 시) |
| 배분기준 | 코스트센터·계정별 귀속 비율, 포트폴리오 드라이버와 측정모형 |

## 5. 표준에 없는 새 열을 분석에 쓰고 싶을 때

외부망에서 버전업이 필요합니다. `src/build_trace.py`에 열과 수식을 추가해 새 버전을 만든 뒤 반입합니다.

## 매크로 없이 쓸 때

원본 시트 4행 머리글 순서대로 열을 맞춰 붙여넣고, 회색 머리글 보조수식 열을 데이터 마지막 행까지 끌어 채우면 됩니다.
