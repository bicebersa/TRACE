# TRACE 사업비 원인추적기 · 프로젝트 정의

- **정식 과제명:** 사업비 변동 원인분석 및 예산 점검 자동화
- **별칭:** TRACE (Trend 추이 · Risk 예산 위험 · Anomaly 이상치 · Cause 원인 · Expense 사업비)
- **환경:** 내부망·외부망 분리. 개발은 외부망에서 가상 데이터로 하고, 실행은 내부망의 Excel 2016 + VBA + HTML로 합니다. 실제 데이터는 외부로 나가지 않습니다.

## 01 문제 정의

### 핵심 질문: 누가 어떤 상황에서 무엇을 어려워하나요?

예산·사업비 담당자는 매월 결산 후 사업비가 왜 늘었는지, 이 추세로 가면 예산이 부족한지를 판단해 보고해야 합니다. 경영진이나 대외기관이 물으면 근거도 제시해야 합니다.

- SAP 예산판은 부서·계정별 분기 실적, 배정, 조정, 잔여를 보여줍니다. 그러나 어떤 전표 때문에 늘었는지는 하나씩 클릭해야 알 수 있어서, 전체 원인을 빠르게 파악하기 어렵습니다.
- 예산판(분기, 부서별), TB(월, 계정별), 전표(건별), BS·PL(재무제표)은 기준 단위가 서로 다릅니다. 그래서 전월·전분기·전년동기 비교를 하려면 손으로 다시 맞춰야 합니다.
- 어느 부서·계정부터 봐야 하는지는 담당자의 경험에 달려 있고, 원인을 확인하려면 부서에 묻고 답을 기다려야 합니다.
- 망분리 환경이라 외부 분석 도구나 AI를 내부 데이터에 쓸 수 없습니다.

### 기대 변화: 어떤 상태로 달라지기를 바라나요?

- 예산판, TB, 전표, BS, PL을 넣으면 사업비의 전월·전분기·전년동기 대비 변화가 부서·계정별로 자동으로 나옵니다.
- 계정별로 예산 여유 / 주의 / 부족 예상이 판정되고, 부족 예상 금액과 예산 소진 예상 월이 함께 나옵니다.
- 우선 확인할 부서·계정 TOP 10이 판단 근거 점수와 함께 나옵니다.
- 항목마다 "~때문일 것 같다"는 원인 후보와 근거 전표가 제시됩니다. 담당자는 전표를 찾는 대신 원인을 확인하고 결론을 내리는 데 집중합니다.
- 사업비가 IFRS 17(GMM) CSM과 당기손익에 준 영향이 포트폴리오별로 나오고, 어떤 전표가 신계약비 경험차이를 만들었는지 바로 확인합니다.
- 엑셀 대시보드와 HTML 대시보드로 같은 결과를 보고·공유합니다.
- 확인된 원인은 코멘트로 쌓여 다음 달 분석과 대외 대응의 근거가 됩니다. 새로 알게 된 적요 표현을 키워드사전에 추가하면 원인 추정 정확도도 높아집니다.

## 02 검증 완료 기준

### 확인할 것: 어떤 가능성을 확인하려 하나요?

- **데이터 확보:** 예산판을 엑셀로 내보낼 수 있는지, 사업비 전표를 적요·거래처·코스트센터가 포함된 형태로 한꺼번에 추출할 수 있는지
- **정합성:** 전표 합계, TB 합계, 예산판 실적 합계, PL 사업비가 서로 맞아서 빠진 데이터 없이 분석할 수 있는지
- **판단 정확도:** 예산 부족 예측과 주의 대상 선정이 담당자의 실제 판단과 맞는지
- **원인 추정 효용:** 규칙 기반 원인 후보가 실제 원인과 얼마나 맞고, 확인 시간을 얼마나 줄이는지
- **운영 가능성:** 내부망 Excel 2016 + VBA에서 실제 데이터 규모로 쓸 만한 속도가 나오는지

### 판단 근거: 어떤 결과면 검증을 마쳤다고 볼 수 있나요?

- 최근 [3]개월 데이터에서 전표 합계, TB 합계, 예산판 실적 합계, PL 사업비의 차이가 0입니다. 차이가 나면 모두 원인을 설명할 수 있습니다.
- 전월·전분기·전년동기 비교 수치가 기존 수작업 결과와 100% 일치합니다.
- 과거 [2]개 분기를 다시 돌렸을 때, 실제로 예산이 부족했던 계정을 모두 '주의' 이상으로 미리 잡아냅니다.
- 주의 대상 상위 [10]건 중 담당자가 "확인할 가치가 있었다"고 판단한 비율이 [70]% 이상입니다.
- 원인 후보가 실제 확인된 원인과 일치하거나 원인을 찾는 데 도움이 된 비율이 [60]% 이상입니다.
- 월 분석·보고 시간이 [X시간]에서 [Y시간]으로 줄어듭니다.
- 전표 [N만 행] 기준으로 불러오기부터 분석 완료까지 [10]분 이내입니다.

## 범위와 단계

- **1단계:** 비교, 예산 판정, 주의 대상 선정 (예산판 + TB)
- **2단계:** 전표 기반 원인 추정과 근거 전표 제시
- **3단계:** 리포트, 월마감 이력, 키워드사전 보강, 엑셀·HTML 대시보드, BS·PL 재무 요약
- **4단계 (v0.4):** IFRS 17 GMM 연결. 사업비 귀속/비귀속 배분, 포트폴리오별 예정 대비 경험차이, CSM 조정(신계약비)과 당기손익(유지·수금비) 구분, 계리 변동표 대사, 원인 전표 제시. PAA는 손익 영향만, VFA(변액)는 구분계리로 제외
- **5단계 (v0.5):** 실제 계정대체 규칙(직접대체 → 투자관련부서 유지비 공통비의 재산관리비 대체 → 부서별 비율), VFA 분석 포함(신계약비 차이 → CSM, 유지·수금비 → 당기손익), 부서 × 계정 × 분기 한도 판정, 대시보드 업로드·탭 분리, 사용설명서
- **후속:** 감독원 실제 양식 반영, 예정사업비 대비 사업비차익 보고서, 월마감 이력 기반 추세 분석
