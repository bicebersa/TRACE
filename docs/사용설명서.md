# TRACE 사용설명서 (v0.5)

같은 내용을 화면으로 보려면 `TRACE_사용설명서.html`을 여세요.

TRACE는 SAP 예산판·시산표·전표와 감독원 양식 BS·PL·보험계약부채 변동표를 받아, 사업비가 왜 늘었는지, 분기 한도를 넘는지, IFRS 17 손익과 CSM에 어떤 영향을 줬는지를 근거 전표와 함께 보여줍니다. 내부망의 Excel 2016 + VBA + HTML만으로 동작합니다.

## 1. 시작하기

### 처음 한 번
1. `TRACE_v0.5.xlsm`을 열고 [콘텐츠 사용] → 설정 시트에 버튼 10개가 자동으로 생깁니다. 한 번 저장합니다.
2. HTML 5개와 `trace.css`, `data.js`를 엑셀과 같은 폴더에 둡니다.

`.xlsx`로 쓸 때: `Alt+F11` → [파일 가져오기] → `modTrace.bas` → `Alt+F8` → `SetupButtons` → .xlsm으로 저장.

매크로가 막혀 있어도 계산은 수식이라 동작합니다. 원본 시트에 붙여넣고 회색 머리글 보조수식을 끌어 채우면 됩니다.

### 매월 할 일
1. 설정 시트에서 기준연도·기준월 변경
2. [불러오기] 버튼으로 파일 선택 (예산판, TB, 전표, BS, PL, 예정사업비, 부채변동표)
3. 자가진단이 "전체 정상"인지 확인
4. 주의대상 TOP 10 → 원인분석 `C5`에 순위 → 원인 후보·근거 전표 확인
5. IFRS17_사업비 시트에서 CSM·손익 영향 확인
6. 확인된 원인을 코멘트 시트에 입력
7. [대시보드 내보내기] → 저장 → HTML 대시보드로 확인·공유

### 버튼
| 버튼 | 하는 일 |
|---|---|
| 예산판·TB·전표·BS·PL 불러오기 | 헤더설정의 열 이름으로 열을 찾아 넣고, 합계 행을 빼고, 보조수식을 채움. BS·PL은 '감독원 (가로)' 옵션이면 기준월 한 달씩 합침 |
| 예정사업비·부채변동표 불러오기 | 계리 자료와 변동표. 변동표에 연도·월이 없으면 기준월로 채우고 그 달만 교체 |
| 보조수식 다시 채우기 | 직접 붙여넣었을 때 보조수식을 데이터 길이에 맞춤 |
| 대시보드 내보내기 | TOP 10 원인분석을 계산해 `data.js`와 숨김 시트 `대시보드데이터`에 저장 |
| 리포트 PDF | 리포트 시트를 PDF로 |

## 2. 엑셀 구성

|---|---|---|

| 입력 | 예산판_원본 · TB_원본 · 전표_원본 · BS_원본 · PL_원본 · 부채변동표 · 예정사업비 | 받은 자료 (A열부터) |
| 기준표 | 계정매핑 · 부서매핑 · 계정대체기준 · 키워드사전 · 코멘트 | 계정·부서 체계, 계정대체 규칙, 적요 키워드, 확인된 원인 |
| 분석 | 자가진단 · 변동분석 · 월별집계 · 계정변동 · 주의대상 · 원인분석 · IFRS17_사업비 · 차트데이터 | 모두 수식 |
| 보고 | 대시보드 · 리포트 · (숨김) 대시보드데이터 | 차트, 인쇄용 보고서, HTML용 결과 |

셀 색: 파란 글씨 입력 · 검정 수식 · 초록 다른 시트 참조 · 노란 배경 설정 · 회색 머리글 보조수식(수정 금지).

## 3. 동작 원리
```
원본 → 보조수식(기간·부서·키·보고단위·계정대체) → 월별집계 · 계정변동(대사) · 변동분석
변동분석 → 분기 한도 판정 · 주의 점수 → 주의대상 TOP 10 → 원인분석(거래처·전표 분해, 8패턴)
계정대체 → 포트폴리오 → 예정 대비 경험차이 → CSM(GMM·VFA) · 당기손익 → IFRS17_사업비 (변동표 F31 대사)
결과 → 차트데이터 → 대시보드·리포트 / 대시보드 내보내기 → data.js · 대시보드데이터 → HTML
```

- **분기 한도 판정:** 통제 단위는 부서 × 계정 × 분기. 분기 한도 = 배정 + 조정. 분기말 예상 = 분기 실적 + 최근 3개월 평균 × 남은 개월. 이미 넘음 = 한도 초과, 예상 100% 초과 = 초과 예상, 90% 초과 = 주의. 연간 전망은 참고.
- **예산 고갈 예상 (선형 추세):** 점 (0,0)…(기준월, 누계실적)에 최소제곱 직선(누계 = 절편 + 기울기 × 월)을 맞추고, 직선이 연간가용에 닿는 시점 (가용 − 절편) ÷ 기울기를 고갈 예상일로 표시. 판정은 이미 소진 · 연내 고갈 · 연내 여유 · 소진 안 됨. 분기 고갈 예상일은 분기 한도 ÷ (분기 실적 ÷ 경과 개월). 변동분석 AP~AW열, 차트데이터 소진 추세 표, 대시보드 사업비 탭. 기울기는 설정 C19에서 고름: 연내누적(최소제곱) / 최근월(당월) / 최근분기(최근 3개월 평균) / 전년추세(작년 같은 남은 기간 월평균). 원인분석 요약의 연간 부족 예상과 고갈일도 이 추세로 계산.
- **주의 점수(100점):** 증가액 30 · 증가율 20 · 이상치 25 · 예산 25. 당월과 증가액이 모두 작으면 30%로 낮춤.
- **원인 패턴:** 일회성 대형 지출 · 신규 거래처 · 단가 인상 · 계상 시점 이동 · 정정·역분개 · 재분류(SA) · 적요 키워드 · 물량 대 단가. 규칙 기반 가설이므로 담당 부서 확인으로 확정.
- **IFRS 17 계정대체:** 특정 계정 → 지정 IFRS 17 계정. 공통비 중 투자관련부서의 유지비 성격분은 연간 비율만큼 재산관리비로, 나머지는 부서별 비율로 신계약·유지·수금·비귀속.
- **반영처:** GMM·VFA 신계약비 차이 → CSM 조정 / 유지·수금비 차이, PAA 신계약비 → 당기손익 / 비귀속 → 기타사업비용 / 재산관리비 → 투자손익.

## 4. HTML 대시보드
| 불러오기 | 방법 | 내용 |
|---|---|---|
| 같은 폴더의 data.js | HTML을 열면 자동 | 전부 |
| data.js·JSON 올리기 | 상단 [자료 불러오기] 또는 끌어다 놓기 | 전부 |
| TRACE 엑셀 올리기 | .xlsx·.xlsm 그대로 (브라우저가 직접 읽음) | 대시보드 내보내기 후 저장한 파일이면 전부, 아니면 저장된 계산값으로 구성(원인 상세는 선택된 1건) |

엑셀 올리기는 Edge·Chrome 최신 버전이 필요하고, 엑셀에서 한 번 열어 저장한 파일이어야 합니다.

탭: 요약 · 사업비 · 주의 대상·원인 · IFRS 17(GMM/VFA 전환) · 재무 요약. 상단 메뉴로 처리 흐름, IFRS 17 연결, 사용설명서 페이지로 이동합니다.

## 6. 점검과 문제 해결
자가진단 33항목: 형식(머리글·보조수식·기준월 자료), 매핑(미매핑·누락·중복·대체비율표), 대사(TB↔전표, 예산판↔전표, BS 대차, PL 검산, 기타사업비용↔비귀속, 재산관리비, 계정대체 전후, 변동표 롤포워드·BS·F31). 외부망으로 오류를 알릴 때는 [점검 항목]과 [상태]만 전달하세요.

| 증상 | 해결 |
|---|---|
| modTrace.bas 한글 깨짐 | CP949로 저장된 원본 파일을 그대로 가져오기 (메모장으로 다시 저장하지 않기) |
| 매크로 실행 안 됨 | 보안 정책 확인. 매크로 없이 붙여넣기 + 보조수식으로도 사용 가능 |
| "필수 열을 찾지 못했습니다" | 메시지의 열 머리글을 헤더설정에 추가 |
| 엑셀이 느림 | 사업비 계정·최근 24개월만 추출, 계산 수동 후 F9 |
| HTML 빈 화면 | data.js가 없음 → 대시보드 내보내기 또는 [자료 불러오기] |
| "계산 결과가 저장되지 않은 파일" | 엑셀에서 열어 저장한 뒤 올리기 |
| "뚜렷한 패턴 없음" | 근거 전표를 직접 확인하고 새 적요 표현은 키워드사전에 추가 |
