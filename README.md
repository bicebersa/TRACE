# TRACE · 사업비 원인추적기

**사업비 변동 원인분석 및 예산 점검 자동화** (Trend · Risk · Anomaly · Cause · Expense)

SAP 예산판·시산표(TB)·전표와 감독원 양식 BS·PL·보험계약부채 변동표를 엑셀에 넣으면 다음을 보여주는 보험사 예산·사업비 담당자용 도구입니다.

- 사업비의 전월 · 전분기 · 전년동월 대비 변화 (부서 × 계정)
- 부서 × 계정 × **분기 한도** 점검 (여유 · 주의 · 초과 예상 · 한도 초과), 연간 전망
- **예산 고갈 예상:** 월별 누계 실적에 직선(최소제곱)을 맞춰 연간 예산이 바닥나는 날과 분기 한도 고갈일 표시
- 먼저 확인할 부서·계정 TOP 10과 증가 원인 후보, 근거 전표
- **IFRS 17 연결 (GMM · VFA · PAA):** IFRS 4·9 전표 → 계정대체(직접대체 → 투자부서 유지비의 재산관리비 대체 → 부서별 비율) → 포트폴리오 → 예정 대비 경험차이 → CSM과 당기손익, 그 원인 전표
- 재무 요약 (BS 추이, PL 월별 손익) · 엑셀 대시보드와 HTML 대시보드(탭 5개, 엑셀·data.js 업로드)

망분리 환경을 전제로 만들었습니다. 내부망에서 **Excel 2016 + VBA + HTML**만으로 동작하며, 인터넷 연결이나 별도 설치가 필요 없습니다.

> 저장소의 모든 금액·거래처·부서·감독원 양식은 **가상 예시**입니다. 실제 업무 데이터는 올리지 마세요.

## 설치 (1회)

1. `TRACE_v0.5.xlsm`을 열고 [콘텐츠 사용]을 누르면 설정 시트에 버튼 10개가 생깁니다 → 저장
2. HTML 5개 + `trace.css` + `data.js`를 엑셀 파일과 같은 폴더에 둡니다

`.xlsx`로 쓸 때: `Alt+F11` → [파일] → [파일 가져오기] → `modTrace.bas` → `Alt+F8` → `SetupButtons` → **.xlsm**으로 저장.

## 매월 사용

1. 설정 시트에서 기준연도·기준월 변경
2. [불러오기] 버튼으로 SAP·감독원 양식 파일 선택 (예산판, TB, 전표, BS, PL, 예정사업비, 부채변동표)
3. 자가진단이 **전체 정상**인지 확인
4. 주의대상 TOP 10 → 원인분석 시트 `C5`에 순위 입력 → 원인 후보와 근거 전표 확인
5. IFRS17_사업비 시트에서 CSM·당기손익 영향과 근거 전표 확인
6. 담당 부서 확인 결과를 코멘트 시트에 입력 → [대시보드 내보내기] → 저장
7. `TRACE_대시보드.html`을 열면 같은 폴더의 `data.js`를 읽습니다. 다른 곳에서는 상단 [자료 불러오기]로 **엑셀 파일 자체**나 `data.js`를 올리면 됩니다

## TRACE 도우미 챗봇 (Vercel)

TRACE 사용법·입력 양식·원인 추정 규칙·IFRS 17 연결을 묻는 챗봇입니다. README와 `docs/`(사용설명서·입력 양식 변경·프로젝트 정의)를 근거로 답합니다. **외부망 서비스이므로 실제 업무 데이터는 입력하지 마세요.**

1. Vercel 프로젝트 이름은 소문자로 정합니다 (예: `vercel --name trace`, 또는 처음 `vercel` 실행 때 이름에 `trace` 입력)
2. Vercel 환경변수
   - `OPENROUTER_API_KEY` (필수)
   - `OPENROUTER_MODEL` (선택, 기본 `nvidia/nemotron-3-super-120b-a12b:free`)
   - `CHAT_ACCESS_CODE` (선택, 설정하면 접속 코드를 입력해야 대화 가능)
3. 배포하면 루트 주소(`/`)가 챗봇이고, 상단 링크로 대시보드·흐름·IFRS17 연결·사용설명서 페이지로 갑니다

다른 주소의 페이지(예: claude.ai의 TRACE 대시보드 아티팩트)에서도 `/api/chat`을 부를 수 있도록 CORS를 열어 두었습니다. 접근을 제한하려면 `CHAT_ACCESS_CODE`를 설정하세요.

화면에서 고를 수 있는 모델은 무료(`:free`) Nemotron 3종(Super · Ultra · 3.5 Lightning)뿐입니다. 서버가 이 목록 밖의 모델 요청을 거절하므로 키의 유료 크레딧이 쓰이지 않습니다.

## 입력 양식 바꾸기

실제 양식이 정해지면 수식은 그대로 두고 표만 고칩니다. 자세한 방법은 [`docs/입력양식_변경방법.md`](docs/입력양식_변경방법.md).

- **헤더설정 시트:** 불러오기가 찾는 열 이름과 대체 이름 (띄어쓰기·대소문자 무시, 열 순서 무관)
- **입력옵션 시트:** 합계 행 제외 키워드, 전표 차대구분(S/H) 방식, BS·PL 감독원(가로) 양식 옵션, BS·PL 항목 매핑, 변동표 요인 매핑

## IFRS 17 연결

```
사업비 전표 (IFRS 4·9) ─ 계정대체 ─┬─ 직접대체: 특정 계정 → 지정 IFRS 17 계정
                                    └─ 공통비 ─┬─ 투자관련부서 · 유지비 성격 × 연간 비율 → 재산관리비 (투자손익)
                                               └─ 남은 금액 × 부서별 비율 → 신계약 · 유지 · 수금 · 비귀속
귀속 사업비 → 포트폴리오 → 예정 대비 경험차이
   ├─ GMM · VFA 신계약비 차이 → CSM 조정 (변동표 F31과 대사)
   ├─ 유지·수금비 차이, PAA 신계약비 차이 → 보험서비스결과 (당기손익)
   └─ 비귀속 → 기타사업비용
```

사업비 가정변경(F21)은 계리 가정의 결과라 전표가 직접 원인이 아니며, BEL 이자부리·RA 해제·할인율 효과는 사업비 전표와 관계없습니다. 측정모형별 처리는 회사 회계정책을 따릅니다.

## 예산 점검 (분기 한도)

예산 통제 단위는 **부서 × 계정 × 분기**입니다. 분기 한도 = 배정 + 조정, 분기말 예상 = 분기 실적 + 최근 3개월 평균 × 남은 개월. 이미 넘으면 한도 초과, 예상 100% 초과면 초과 예상, 90% 초과면 주의. 연간 전망은 참고로 함께 계산합니다.

## 원인 추정 규칙 (원인분석 시트)

| 패턴 | 판단 규칙 | 근거 강도 |
|---|---|---|
| 일회성 대형 지출 | 전표 1건이 증가분의 50% 이상이고, 그 거래처 평소 월평균의 3배 이상 | 높음 |
| 신규 거래처 | 최근 12개월 거래 없던 거래처가 증가분의 30% 이상 | 중간 |
| 단가 인상 | 같은 건수에서 금액이 5~50% 상승 | 중간 |
| 계상 시점 이동 | 전월이 평소의 절반 미만, 당월이 평소의 1.5배 초과 | 중간 |
| 정정 · 역분개 | 당기에 음수 전표 존재 | 높음 |
| 재분류 (수기 대체) | SA 전표 순증이 증가분의 30% 이상 | 높음 |
| 적요 키워드 | 키워드사전(연간·캠페인·재분류·판매시책 등) 해당 전표가 증가분의 30% 이상 | 중간 |
| 물량 vs 단가 | 건수 변화와 건당 금액 변화로 분해 | 참고 |

## 예시 데이터 다시 만들기 · 검증

```bash
pip install openpyxl formulas
python src/build_trace.py                       # TRACE_v0.5.xlsx
python src/build_datajs.py                      # data.js (엑셀 수식과 같은 로직)
EMBED_JSON=data.js python src/build_trace.py    # 결과 내장본 (엑셀만 올려도 대시보드가 읽음)
python src/build_vba.py                         # modTrace.bas
python src/build_xlsm.py                        # TRACE_v0.5.xlsm (매크로 내장)
python src/build_sample_fss.py                  # samples/샘플_감독원양식_2026-09.xlsx
python src/build_forms.py                       # samples/TRACE_입력양식_v0.5.xlsx (본체 헤더설정에서 생성)
python src/build_bundle.py                      # TRACE_v0.5_전체.zip (내려받기 페이지용 전체 묶음)
python tools/verify.py                          # 수식 검증 (10분 안팎)
```
